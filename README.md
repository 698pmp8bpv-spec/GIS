# نتائج اختبار نظم المعلومات الجغرافية · تلفون المعلم

هذي الصفحة تفتح على تلفون المعلم وتجمع نتائج الطلاب، **بدون ما تحتاج إنترنت في المدرسة**.

## كيف توصل النتائج للتلفون

1. **برنامج الطالب (exe):** في آخر الاختبار يطلع رمز QR، فيه نتائج كل اللي حلّوا على نفس الكمبيوتر اليوم.
2. **برنامج المعلم (exe):** زر **إرسال للتلفون (QR)** يطلع رمز فيه كل النتائج اللي وصلت له، أو نتائج الشعبة المختارة.
3. امسح الرمز بكاميرا الآيفون، وتنفتح هذي الصفحة وتضيف النتائج. تقدر بعد تمسح من داخل الصفحة بزر **مسح QR**.

## في الصفحة

- ترتيب حسب الدرجة ثم الوقت، مع فلتر الشعب والبحث بالاسم.
- **ترتيب المراكز (أفضل ١٠):** منصة تتويج لأول ثلاثة، مع عرض تدريجي.
- حفظ النتائج كملف **HTML** بنفس الثيم، أو ملف نصي، أو Excel.

النتائج تنحفظ على التلفون نفسه. وإذا فيه أكثر من معلم، كل واحد يمسح الرمز بتلفونه.
